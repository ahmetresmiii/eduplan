# EduPlan

EduPlan, öğrencilerin akademik süreçlerini daha düzenli ve verimli bir şekilde yönetebilmeleri için geliştirilmiş, modern web teknolojileriyle hazırlanmış bir akademik planlama sistemidir.

## 🚀 Proje Hakkında
Bu platform, eğitim hayatındaki çalışma süreçlerini dijitalleştirmek, akademik hedefleri takip etmek ve günlük çalışma planlarını organize etmek amacıyla tasarlanmıştır. Öğrencilerin kendi gelişimlerini şeffaf ve düzenli bir şekilde izleyebilmelerini hedefler.

## 🛠 Kullanılan Teknolojiler
* **Frontend:** Modern web standartları (HTML, CSS, JavaScript).
* **Platform:** GitHub Pages üzerinden yayında.

## 💡 Temel Özellikler
* **Akademik Planlama:** Ders çalışma programlarını yönetme ve düzenleme.
* **Gelişim Takibi:** Akademik ilerlemeyi dijital ortamda kaydetme.
* **Kullanıcı Deneyimi:** Sade, hızlı ve mobil uyumlu arayüz.
